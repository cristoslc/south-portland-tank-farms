Data Files

GIS-ready datasets used in the research. Coordinates are WGS84 (EPSG:4326); distances are straight-line fence-line distances from OpenStreetMap-mapped structures. See the research report for methodology and caveats, and the fact-check log for claim-by-claim verification.

FileContentsFormatUse
receptors_points.csvReceptor point layer (171 sites)
One row per receptor: lat/lon, WKT, distances in miles + meters to each farm fence line, within-1-mile flag.		CSVQGIS: Layer ▸ Add Layer ▸ Delimited Text (point coordinates, EPSG:4326)
receptor_farm_distances_long.csvTidy distances (171 × 6 farms)
Long format: one distance per receptor-farm pair, with within_1mi flag. Best shape for joins/pivots/database loads.		CSVAny spreadsheet, R (read.csv), pandas, or Postgres COPY
receptor_counts_by_farm.csvPer-farm within-1-mile counts
Summary table: counts by category for each of the six facilities.		CSVDirect reference table
tank_farm_facilities.csvTank farm facilities (6)
Facility coordinates, DEP license numbers, renewal dates, facility-wide VOC/HAP limits.		CSVGIS point import or tabular reference
tank_farm_structures.geojsonFence-line structures (117 + 8 excluded)
OSM polygons: storage tanks + qualifying parcels, with farm assignment and exclusion reasons for non-tank-farm structures.		GeoJSONQGIS/geojson.io/Leaflet — loads directly
tank_farm_1mile_buffer.geojson1-mile fence-line buffer zone
Single merged polygon: union of all qualifying structures buffered one statute mile. Point-in-polygon = the report's 'within 1 mile' criterion (41/42 exact; 1 boundary case at 1.000 mi).		GeoJSONQGIS/geojson.io/Leaflet — loads directly
receptor_fenceline_distances.csvMaster dataset (original wide format)
Original analysis dataset with per-farm distance columns (miles).		CSVSuperseded by receptors_points.csv for GIS use; retained for lineage
License & provenance. Data: CC BY 4.0. Fence-line geometry: OpenStreetMap contributors, ODbL 1.0, via the project's self-hosted Overpass instance (osm.cristoslc.com, Maine daily extract, base 2026-09-27T20:10Z). Child care listings: Maine OCFS Child Care Choices (captured Sept 24, 2026). Schools: NCES. Senior housing: SPHA + state-licensed facilities. Repo mirrors everything at github.com/cristoslc/south-portland-tank-farms.

Note: fence-line polygons are community-mapped OSM data; City of South Portland assessor GIS parcels would be the parcel-exact upgrade. Distances < ~0.01 mi mean the receptor point sits on/inside the mapped parcel edge ("directly adjacent").
